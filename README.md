# 🌿 SoulUp — Plataforma de Gamificação Sustentável

## 📖 Sobre o Projeto

O **SoulUp** é uma plataforma web desenvolvida com foco em sustentabilidade e gamificação, criada para incentivar usuários a adotarem hábitos sustentáveis no dia a dia.

A proposta do projeto é transformar ações sustentáveis em pontuação, criando um ambiente competitivo e motivador através de rankings, recompensas e acompanhamento de desempenho.

O sistema foi desenvolvido como parte do desafio acadêmico da FIAP em parceria com a empresa fictícia **Prospera / SoulUp**.

---

# ✨ Funcionalidades

## 🏆 Ranking Global

* Sistema de ranking com classificação dos usuários
* Pódio dos melhores colocados
* Tendência de subida e descida no ranking
* Contadores animados de pontuação
* Countdown para encerramento da competição

## 📊 Dashboard

* Visualização de desempenho do usuário
* Acompanhamento de pontos
* Estatísticas de ações sustentáveis
* Interface moderna e responsiva

## ❓ FAQ Interativo

* Perguntas frequentes com animações
* Sistema de accordion interativo

## 📩 Contato

* Formulário de contato validado via JavaScript
* Feedback visual para o usuário

## 🌱 Gamificação Sustentável

* Sistema de recompensas
* Competição entre usuários
* Incentivo a hábitos sustentáveis
